## v1.6.1-fork.2

This downstream release builds on [v1.6.1-fork.1](v1.6.1-fork.1.md) and upstream [v1.6.1](v1.6.1.md). It brings native SSH remote monitoring to Windows, adds a per-user Windows installer alongside the portable ZIP, and directs the macOS, Windows and Linux updaters to the fork's releases at `yooztech/agent-speed`.

### Remote monitoring

- On macOS and Windows, configure an SSH alias or destination for the Linux account owning the agent logs, trust the host key in advance, and use noninteractive key or SSH-agent authentication. Enable the host in **Settings → Sources**. Windows uses its native OpenSSH client; install or enable it if unavailable. Disable a host to stop monitoring it; remote monitoring is independent of the app's network switch.
- The app uploads its bundled collector and runs it over SSH standard streams. No listening port, HTTP service, Python or sudo is required. The collector reuses the Linux measurement core, including omp parsing and parent/child deduplication.
- Local and enabled remote hosts are simultaneous standard sources, grouped by host and source in the native dashboard. Available statistics contribute to the native aggregate; there is no dashboard target switch. Offline hosts are identified as offline, unavailable data is not zero, and offline history remains a gap. History export matches visible history; local diagnostic reports exclude remote data.
- The collector keeps a private cache at `~/.cache/agentspeed-collector/history.sqlite3` on the Linux host. Concurrent collectors or an unsafe or unavailable cache use memory instead. Changes to monitored source configuration reset the cache.
- On macOS and Windows, floating orb source settings allow selecting sources by host and source, including enabled remote hosts.

### Downloads and updates

- Windows releases provide `AgentSpeed-Windows-x64.zip` and `AgentSpeed-Windows-arm64.zip` for portable use, and `AgentSpeed-Windows-x64-Setup.exe` and `AgentSpeed-Windows-arm64-Setup.exe` for per-user installation. The installer defaults to `%LOCALAPPDATA%\Programs\AgentSpeed`, does not require elevation, and offers optional desktop and startup shortcuts.
- macOS bundles and both Windows package types include the Linux x86_64 collector. Release packaging uses the collector built on Ubuntu 22.04; CI compares the Windows ZIP collector with that build and checks the installed collector in native installer smoke tests. Release checksums cover both Windows package types.
- All three desktop platforms check the fork's GitHub releases rather than upstream releases. The prepared application version is `1.6.1-fork.2`; the release tag is `v1.6.1-fork.2`.

### Limitations and verification status

- **Real GUI SSH end-to-end operation against an actual remote host has not been verified.** Automated checks and packaging do not establish host compatibility or validate the complete connection, disconnect and reconnect experience.
- The bundled collector supports **Linux x86_64 only**. It is dynamically linked and needs compatible runtime libraries on the remote host; Linux desktop packages for other architectures do not imply collector support.
- Metrics depend on the logs. Missing fields remain unknown; rates inferred from recent completed responses are estimates. omp commonly records responses only when complete, so per-token streaming speed and unrecorded time to first token cannot be measured; unrecorded router retries and account cooldowns are also unknown.
- The remote protocol provides source, agent and history aggregates, but not categorized today's tokens, project paths, traffic or continuous curves. Initial history scans can take considerable time and resources. A `partial` history flag reports known discovered-file and database errors; a clear flag does not guarantee exhaustive discovery or filesystem readability.
